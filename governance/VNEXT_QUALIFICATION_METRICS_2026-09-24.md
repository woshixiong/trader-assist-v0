# VNext Qualification Metrics

## Goal

Measure whether the new governance flow improves reliability, clarity, and token efficiency.

## Metrics

### Routing Quality

- Correct next destination
- Explicit command generation
- Failure loop closure

### Execution Quality

- Number of unnecessary context transfers
- Number of repeated semantic executions
- Recovery success after interruption

### Human Boundary Quality

- Protected actions requiring approval
- Non-essential interruptions removed
- Final authorization clarity

### Token Efficiency

Track:

- planning overhead
- duplicate reviews
- unnecessary model calls
- repeated state transfer

## Acceptance

The candidate flow should reduce ambiguity while preserving review quality and protected gates.
