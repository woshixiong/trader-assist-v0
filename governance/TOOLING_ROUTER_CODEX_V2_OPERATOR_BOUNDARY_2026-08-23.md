# Tooling Router / Codex V2 — Semantic Writer / Operator Boundary

Use this boundary to avoid both wasted frontier tokens and unnecessary handoffs.

```text
SEMANTIC WRITER OWNS:
  code inspection requiring judgment
  implementation
  in-scope repair
  focused/relevant validation
  semantic self-check
  exact artifact freeze

DETERMINISTIC OPERATOR MAY OWN WHEN AUTHORIZED:
  status/diff/evidence collection
  mechanical formatting or transport
  commit/push of the frozen artifact
  CI observation/polling
  browser/file/terminal transport
```

A free operator is used only when it reduces total burden. Do not create a mandatory handoff for a tiny tail that the current Writer can finish more cheaply, and do not ask the operator to re-read/reason over the entire codebase.

The operator receives exact worktree/artifact/Task Packet identity and fails closed on drift or semantic ambiguity.
