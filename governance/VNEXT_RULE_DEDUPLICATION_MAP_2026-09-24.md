# VNext Rule Deduplication Map

## Goal

Reduce governance complexity by separating stable principles from operational procedures.

## Keep in Constitution

- source of truth rules;
- role boundaries;
- protected actions;
- escalation principles;
- validation philosophy.

## Move to Procedures

- Codex launch steps;
- review commands;
- recovery flows;
- model routing details;
- CI handling details.

## Archive

- superseded experiments;
- historical research notes;
- obsolete workflow descriptions.

## Expected result

Future changes should update one layer only instead of multiple overlapping documents.
