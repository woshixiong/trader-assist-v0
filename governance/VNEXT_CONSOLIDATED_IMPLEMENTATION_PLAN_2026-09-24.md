# VNext Consolidated Implementation Plan

## Purpose

Consolidate preparation artifacts into an executable migration sequence.

## Migration order

1. Freeze V4 active behavior.
2. Replace duplicated routing documents with a single manifest-driven model.
3. Thin AGENTS into an entry router.
4. Move operational details into triggered procedures.
5. Keep Codex runtime policy separate from governance constitution.
6. Validate through qualification runs before activation.

## Activation rule

Preparation documents do not become active policy until the manifest transition is reviewed and approved.

## Success criteria

- one active constitution;
- one routing manifest;
- deterministic handoff format;
- explicit failure routing;
- minimal human interruption without removing protected gates.
