# Engineering Governance VNext

Status: candidate only. V4 remains active until explicit activation.

## Source of Truth
GitHub is the canonical engineering source of truth.

## Layers

1. Constitution: principles, authority boundaries, role separation.
2. Procedures: triggered workflows and failure routing.
3. Runtime: execution configuration and checkpoints.

## Roles

- Engineering Control: scope, route, freeze, escalation.
- Codex: implementation within approved scope.
- Independent Reviewer: read-only evidence verification.
- Human: protected actions.

## Protected Actions

MARK_READY, MERGE, DEPLOYMENT, production mutation, credentials, wallet/signing and trading actions require explicit authority.

## Migration Rule

This file cannot activate itself. Activation requires qualification evidence and human approval.
