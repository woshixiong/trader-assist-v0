# VNext Procedure Routing Matrix Draft

Status: DRAFT ONLY

| Need | Owner | Route |
|---|---|---|
| Mechanical deterministic change | Tooling | Zero-model tool |
| Bounded implementation | Writer | Scoped implementation procedure |
| Large coherent coding package | Codex | Plan-only -> Goal -> implementation |
| Architecture/security/authority issue | Engineering Control | Re-plan |
| Independent validation | Fresh Reviewer | Read-only evidence review |
| Protected action | Human | Explicit authorization |

## Failure routing

- Pre-code review failure: return to the owner of the failed artifact with an explicit next command.
- Implementation failure: remain in bounded repair loop unless scope expands.
- Final review failure: return to Engineering Control for re-planning.
