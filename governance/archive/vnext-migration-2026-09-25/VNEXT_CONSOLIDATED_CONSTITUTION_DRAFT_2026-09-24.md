# VNext Consolidated Constitution Draft

Status: preparation only. V4 remains active until explicit activation.

## Core Principles

- GitHub is the canonical engineering source of truth.
- Roles, authority, execution surface, and acceptance criteria must not drift silently.
- Governance defines boundaries; procedures define operations.

## Roles

Engineering Control: scope, architecture, routing, freeze decisions.

Writer/Codex: implementation within bounded scope.

Reviewer: independent evidence-based validation.

Human: retained protected gates.

## Execution Model

Route work by evidence:

- deterministic work -> deterministic tools
- bounded semantic work -> lightweight model
- coherent coding -> Codex
- unresolved architecture/security -> Engineering Control

## Protected Actions

Explicit authorization remains required for protected mutations including merge, deployment, production changes, credentials, and trading actions.
