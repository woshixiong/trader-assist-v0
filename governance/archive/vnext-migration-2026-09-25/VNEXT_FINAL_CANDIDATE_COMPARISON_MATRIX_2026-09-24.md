# VNext Final Candidate Comparison Matrix

## Purpose

Compare current V4 governance with VNext candidate before activation.

| Area | Current State | VNext Goal |
|---|---|---|
| Entry point | Multiple references | Single routing entry |
| Rules | Mixed principle/procedure content | Layered governance |
| Runtime | Partially coupled | Explicit runtime policy |
| Handoff | Human interpretation required | Structured next action |
| Failure routing | Case dependent | Deterministic routing |
| State | Transcript dependent risk | Artifact/checkpoint based |

## Migration Principle

Improve operational clarity without changing engineering authority boundaries.

## Activation Constraint

VNext must preserve all existing safety gates before replacing V4.
