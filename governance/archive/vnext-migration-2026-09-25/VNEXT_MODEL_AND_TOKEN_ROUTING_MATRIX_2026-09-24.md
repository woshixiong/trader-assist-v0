# VNext Model and Token Routing Matrix

## Principle
Use the minimum capable execution route. Preserve high-capability models for high-value reasoning.

## Routing

Mechanical tasks:
- deterministic tools
- zero unnecessary model reasoning

Small semantic tasks:
- lightweight model/context
- bounded scope

Large coding packages:
- Codex execution route
- structured plan and goal boundaries

Architecture/security/high consequence:
- Engineering Control
- strongest available reasoning

## Token Control Rules

- Store durable state in GitHub artifacts.
- Avoid repeating large transcript context.
- Do not use multiple agents when serial execution is sufficient.
- Escalate model capability only when evidence requires it.

VNext remains inactive until qualification approval.
