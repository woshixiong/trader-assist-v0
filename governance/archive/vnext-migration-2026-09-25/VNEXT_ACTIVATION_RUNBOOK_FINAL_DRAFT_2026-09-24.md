# VNext Activation Runbook Final Draft

## Preconditions

Activation requires:

1. Qualification completed.
2. Final result recorded.
3. No unresolved routing or authority conflicts.
4. Human approval for protected migration actions.

## Activation Sequence

1. Update governance manifest.
2. Update AGENTS entry routing.
3. Update project instruction reference.
4. Validate fresh project entry behavior.
5. Begin first production qualification cycle.

## Rollback

If qualification fails:

- keep previous governance active;
- revert activation candidate changes;
- repair VNext candidate;
- repeat qualification.
