# 人工交易策略指南：Brooks / Louie × Trade OS

**版本**：`PA_HUMAN_GUIDE_V0_20261016`  · **状态**：研究参考 / 待试验，不替代当前人工风控规则。  
**适用**：日内价格行为；优先观察 SKHX / MU / SNDK，扩展至有足够流动性的指数等低摩擦市场。首选 5m 判断背景、1m 找时机，需要时参考 15m / 60m。**不是针对所有市场有效的保证。**

## 0. 一屏操作卡（依次执行）

```text
[环境 STATE] 强趋势 / 宽通道 / 震荡？ 看不清 = 等待
[位置 LEVEL] 是否在有因果依据的前高低、区间边缘、回测位、开盘区间？
[结构 SETUP] 影线拒绝 / 假突破回收 / 顺势回调二次入场 / 突破回测？
[信号 TRIGGER] 收线后是否有强势反向/顺势 K？1m 是否确认？有无跟随？
[失效 INVALIDATION] 哪一价格或后续行为会证明当前尝试失败？
[空间 ROOM] 目标结构空间能否覆盖手续费、价差、滑点与失败尝试成本？
[风险 RISK] 先确定可承受损失、保护止损、用仓位匹配风险；超预算=不做
入场 → 判断后续跟随/失效 → 退出弱尝试 / 持有合格趋势
```

**禁止**：亏损方向加仓摊平、为追回损失而不经新信号立即重进、因为“已经亏了一点”就机械地马上再试、让保护止损距离超过风险预算。现有风险规则、人工交易阶段目标及 Issue #171 的当期限制始终优先。

## 1. 先分类行情（优先于任何漂亮 K 线）

| 行情类型 | 可观察的特征 | 优先行动 | 回避 |
|---|---|---|---|
| 强趋势 / 窄通道 | 连续同方向强实体、相对少重叠、回调浅、突破后有跟随 | 顺大方向找第一次/第二次回调，或突破-回测-再加速 | 第一次反向长影线就猜顶猜底 |
| 宽通道 / 弱趋势 | 看似有方向，但回调深、K 线重叠、频繁反向实体 | 顺大方向择优；有关键位+二次信号时研究反转 | 误以为每个加速大实体都是真突破 |
| 震荡区间 | 来回重叠、突破反复失败、上下界清晰 | 上下沿做拒绝/假突破，偏短线处理 | 区间中间追单、无止损赌突破 |
| 模式无法确认 / 波动异常 | 强双向冲击、跳空/事件冲击、数据或执行价不可靠 | WAIT / BLOCKED（按原因区分） | 随意选方向 |

从高周期到低周期：结构背景先于小 K 线；强趋势内的下影线可能只是回调，而非有利的反转信号。所有“强”“窄”描述都是人工视觉标签，未来量化须明确参数，不能主观回填历史。

## 2. 四种优先人工执行模式

### M1 关键位影线拒绝（既有 A/B/C 的安全增强）

- **背景**：前高低、区间边缘、明确回测位；强窄趋势中逆势时降低优先级。
- **观察**：5m 明显长影线、小实体尝试拒绝；5m 完成前最后的 1m 是否有可信的反向力量。
- **A/B/C 原始版本保持不变**：A=影线反向；B=A+1m 明显更强的力度；C=B+吞没（严格）。本文件不重定义已有 A/B/C，也不把未收 5m 的形态当成已完成 5m。
- **入场**：仅在既有规则允许且可明确失效时，选择 5m 收线确认，或把收线前 1m 入场明确标成 **EARLY / 未确认 / 更高误判风险** 的单独实验，不混合回测结果。
- **出场**：1m/5m 无跟随、结构拒绝失败、或风险止损触发则退出；形成持续顺向推动后才切换趋势持仓管理。
- **不做**：影线虽长但就在强顺势通道里，或剩余空间被成本消耗。

### M2 第二次入场：H2/L2、双底/双顶与反转的第二次尝试

- **顺势 H2/L2**：上涨趋势里价格第一次企图结束回调上涨（H1）未有效延续，回调继续/再试后第二个合法买入触发（H2）；下降趋势镜像 L2。不是简单“第二根阳线/阴线”。
- **逆势第二次反转**：在重要支撑/阻力，一次反转尝试失败后，重新出现强反向信号与更有利的位置；通常需要双底/双顶、楔形三推或失败新高/新低等背景。
- **入场**：明确信号 K 和触发方向（例如突破信号 K 的高/低），**触发时必须仍然合法**；宁可错过，不为了凑第二次而追。
- **失效**：第二信号缺乏跟随、反向新极值使论点不成立、剩余利润空间低于成本。
- **限制**：上一次 Attempt 失败之后的再入场必须有 **新的可观察触发**，不是因为亏损后的情绪或相同旧信号重复触发。

### M3 顺势突破 → 跟随 → 回测 → 再加速

- **背景**：突破前已识别关键水平位/整理区/通道，且有可用的回测空间。
- **确认**：不是一根大实体就追；重点看它是否收在突破方向、随后是否有有效跟随、有没有立刻退回原区间。
- **入场方式**：直接突破或回测再加速是两个不同实验；人工优先采用更能辨识风险的位置；突破走远且风险/空间不匹配则 PASS。
- **失效**：突破后连续弱跟随、回到原区间、回测位不被守住。
- **管理**：可靠强趋势才持波段；若转为来回重叠的弱走势，不强求趋势目标。

### M4 开盘试探/假突破反转（仅观察/研究，不自动放行）

- 记录美股和韩国开盘时前高低/首段区间、最初推动、前一交易时段位置、是否出现反向突破失败与跟随。
- 观察最早 1m 的反向力度，不等于无条件开盘反向交易；ES 的开盘经验概率不自动转移到 Hyperliquid RWA 24h 定价或其他交易制度。
- **若当前适用的人类阶段规则禁止开盘后前 15 分钟新仓，则只能记录观察样本，不能以本指南绕过此门槛。**
- 只把“开盘 10–60 秒”作为预注册候选观察窗口，计入延迟/滑点/不同开盘制度及新闻风险；不作为已验证策略。

## 3. 入场后按市场证据做决定

| 出现的证据 | 处理 |
|---|---|
| 刚入场立即不利运动，原来的价格假设失效 | 提前离场或硬止损，绝不逆向摊平 |
| 尚在保护止损内，但连续几根 K 无法形成预期跟随 | 重新比较“持仓 vs 平仓”的边际价值；允许主动小损/保本出场；不因价格略红即一律出场 |
| 顺向强实体 + 高/低点沿趋势方向推进，结构仍成立 | 尽量保护右尾，不因固定小目标自动全部止盈 |
| 突破突然转为明显重叠/区间 | 降低持有波段的预期，允许部分/全部离场（拆单比例不是已授权固定参数） |
| 趋势转弱、相反强信号、支持结构破坏 | 动态保护/退出，尊重先前设置的保护性硬止损 |
| 刚止损且仍想继续同向尝试 | 回到 STATE+LEVEL+SETUP+TRIGGER；必须有新信号、风险预算、当期尝试次数门槛才可能重进 |

保护性止损是异常行情保险而非“亏到那里才有资格平仓”。**止损价格由失效结构确定，风险美元由仓位确定**。例如止损过宽则缩小仓位或放弃，不能无限收紧止损来制造“理论上很小的风险”。

剥头皮与波段不应在入场前被永久二选一：**先看后续跟随，趋势成立则持有，弱跟随则及时退出**。真实退出由成交条件与成本约束，不应因为视频中的示例交易赚钱就采用相同持仓时间。

## 4. 手动执行与复盘纪律

- **每次入场前**：说出当前环境、关键位、模式、触发、保护止损、实际成交后估计损失以及可用空间；无法说清就不做。
- **每次入场后**：标记预计多少时间应出现第一轮跟随，以及什么后续行为足以否定（不是事后看结果再调整定义）。
- **同方向再次入场**：记录上次 Attempt ID 与“新的因果触发”，没有新的信息则不重进。
- **事件风险**：当期经济日历和重大事件/交易所异常规则优先；心理/疲劳异常由本人直接判断，不从盈亏推断。
- **最小复盘记录**：品种、交易时段、截图/时间戳、5m regime、位置、A/B/C、M1~M4、信号 K、触发价、保护止损、入场时间和成交方式、预期跟随、无效条件、实际入出场价、手续费/价差/滑点、MAE/MFE（有行情路径才计算）、第一/第二次 Attempt、出场原因和违反规则与否。
- **复盘评价**：把「按规则但亏钱」与「违规但赚钱」分开；短期盈亏无法证明该规则有效。

## 5. 极简记忆法

**先分趋势与震荡，后找关键位置；等一根真正的信号，看它有没有跟随；失败快走，成功拿住；不摊平，不盲目重进。**
