# Security Policy

## Current ceiling

This repository is contract-only. It must not contain exchange credentials, wallet material, signing code, order submission, or live account identifiers.

## Reporting

Treat exposed secrets, unauthorized exchange-write paths, approval bypass, permit replay, evidence tampering, stale-data execution, ambiguous-order recovery, and dependency compromise as security incidents.

Do not include secrets in issues, pull requests, screenshots, logs, fixtures, or test output. Revoke exposed credentials outside the repository before documenting the incident.
